# Licensing map

SpaghettiLAB Community is a multi-license repository. The licence nearest to a file
controls that file; this document is an index and does not replace the licence texts.

| Area | Licence | Commercial use | Reciprocity |
|---|---|---:|---|
| `hardware/` | CERN-OHL-S-2.0 | Yes | Strongly reciprocal hardware licence |
| `firmware/` | GPL-3.0-or-later | Yes | Strong copyleft when covered code is conveyed |
| `software/` | AGPL-3.0-or-later | Yes | Strong copyleft including modified network use |
| `contracts/` | Apache-2.0 | Yes | Permissive interoperability contracts |
| `software/micro-flow-editor/packages/protocol-sdk/` | Apache-2.0 | Yes | Permissive integration SDK exception |
| `software/dashboard/packages/dashboard_domain/` | Apache-2.0 | Yes | Permissive Dashboard domain exception |
| `docs/` | CC-BY-4.0 | Yes | Attribution required |
| Root project metadata and contracts, unless marked otherwise | Apache-2.0 | Yes | Permissive |

The full texts are stored at `hardware/LICENSE`, `firmware/LICENSE`,
`software/LICENSE`, `contracts/LICENSE`, the exception directories listed above and
`docs/LICENSE`. Third-party components retain their own terms and notices.

Open-source and open-hardware licences do not certify a product, provide warranty,
grant support, or grant rights to present a third-party product as official
SpaghettiLAB hardware. See `COMMERCIAL.md` and `TRADEMARK.md`.

Revisions published before the copyleft transition retain the permissions already
granted under Apache-2.0. The transition applies to the new repository generation and
does not retroactively withdraw old grants.
